# Alpha Echo

本地运行、单用户使用、以持仓为中心的跨市场交易情报与决策辅助系统。

当前实现已建立 V1 的本地持仓、研究与报告闭环：

- PostgreSQL 保存账户、标的、不可变持仓快照和版本化交易意图。
- Rust/Axum 提供事实层 API、报告入队 API 和后台任务状态机。
- 报告在创建时固化截止时间、完整持仓事实、有效 Trade Intent 版本、来源快照、事件与上一版叙事。
- 启用研究执行器后，后台 worker 使用本地 Codex 在只读 sandbox 中执行一条精简的股票研究链：共享宏观、按持仓市场加载市场/行业背景、逐持仓诊断、组合构建分析和统一报告合成。
- 研究任务数按实际股票持仓动态生成：共享宏观与市场背景后，每条当前股票持仓各自启动一个独立诊断；互不依赖的市场背景和逐持仓任务并行运行，最后才进入组合构建。
- 每条股票诊断绑定精确的持仓快照明细；Rust 验证范围内所有持仓恰好被覆盖一次，既不漏诊也不重复。
- 创建报告时，后端会按每个 A股、港股、美股持仓自动抓取 Google News 与 Bing News RSS，在报告的 REPEATABLE READ 事务中固化为不可变 `equity_news` 来源快照。逐持仓研究先消费该快照，再使用 Codex live search 核验原文、补充发行人/交易所/监管来源并向最近财报或年度披露回溯。
- 报告和决策台将精确绑定标的的证据拆成“公司与产品动态”和“行业与政策动态”；政策或行业消息只有在明确点名标的或具备直接传导时才能绑定，并且不能替代公司级证据。
- 缺少有效 Trade Intent 时，逐股研究必须输出基于已验证证据的所选报告语言的 Intent 草稿；草稿按精确账户、标的和持仓快照明细展示，只有用户采用、编辑并确认后才成为有效 Intent，未确认时不可产生买卖或仓位动作。
- Worker 使用独立心跳恢复中断任务，保留原始开始时间；Skill 修复后只重试旧版本失败任务，已验证完成的断点继续复用。
- Rust 独立校验 JSON Schema、截止时间、类型化对象 ID、证据引用、事件/叙事/传导到 Finding 的可引用关系、枚举和置信度；无效输出不会进入正式报告。
- Research Runs 保存专项 Skill 与公共研究标准 Skill 的 SHA-256、明确模型、冻结输入、来源证据、发现、叙事、传导路径、原始输出和数据缺口；Briefing 同样保存原始合成 JSON。
- 尚未配置研究执行器时，系统明确产出 `partial` 报告和数据缺口，不伪造市场观点。
- React 工作台以买入/卖出为唯一日常录入入口，自动聚合当前持仓、移动平均成本和已实现盈亏，并可就地编辑持仓逻辑；账户和标的维护收纳为低频操作。
- 每笔手工成交都会写入不可变成交记录并生成新的聚合持仓快照；成交价不会冒充参考现价，新仓位在行情来源首次同步成功前明确显示待同步。
- 账户中最新一笔错误手工成交可审计撤销：原成交保留作废标记，系统创建纠正快照恢复成交前持仓，不删除或覆盖历史事实。
- A 股、港股和美股账户及标的分别固定使用 RMB、HKD 和 USD，数据库迁移与约束共同防止币种错配。
- 通用来源 Adapter 可固化行情、公告和新闻 Payload。

当前只提供股票持仓研究；Meme 竞技场及 GMGN 集成已移除。每个股票持仓诊断固定覆盖宏观、行业、公司、市场定价、未来预期、预期差、上行催化剂、下行压力和核心风险九个维度；组合阶段再处理仓位、集中度、共同风险因子和风险预算。

## 本地运行

### 共享仓库与隐私

本共享版本使用重新创建的 Git 历史，不携带原开发仓库的提交、分支、
reflog 或作者身份。保留的 audit.md 中旧提交引用仅作为历史开发记录，
不会在本仓库中解析到旧提交；个人路径和真实持仓标识已去标识化。

仓库不包含真实 `.env`、数据库内容、研究报告或私有备份。首次运行请从
`.env.example` 创建自己的配置，不要复用他人的配置或凭据。日志、导出、
密钥和数据库备份被 Git 忽略；上传前仍需检查新增文件。不要将整个本地
目录或仓库外的私有备份打包分享，应只分享 Git 仓库中的文件。
可选的 Compose 配置不再内置密码，使用时须自行设置 `POSTGRES_PASSWORD`。

本应用仅适合本机单用户使用，尚无登录或多租户隔离。不要直接暴露到
公网。AI 研究会访问外部模型服务和新闻源，本地数据库不意味着离线推理。
如凭据曾对外泄露，必须在服务提供方撤销或轮换；删除 Git 历史不能使其失效。

需要 Node.js 22+、Rust 1.92+ 和本机 PostgreSQL 15+。默认连接 `127.0.0.1:5432`，不依赖 Docker。

```bash
cp .env.example .env
createdb alpha_echo

cd backend
cargo run
```

另开终端启动仅监听本机的 Vite Web：

```bash
npm install
npm run dev
```

- Web：http://127.0.0.1:3000
- API：http://127.0.0.1:8088
- PostgreSQL：127.0.0.1:5432

后端启动时自动运行 `backend/migrations` 中的 SQLx migrations。

### 启用本地 Codex 研究

先确认本地 Codex CLI 已登录，再在 `.env` 中明确启用并固定模型：

```dotenv
CODEX_RESEARCH_ENABLED=true
CODEX_BINARY=codex
CODEX_RESEARCH_MODEL=gpt-5.6-sol
CODEX_RESEARCH_REASONING_EFFORT=medium
CODEX_RESEARCH_TIMEOUT_SECONDS=900
CODEX_RESEARCH_MAX_ATTEMPTS=2
```

执行器使用 `codex --search -s read-only -a never ... exec --ephemeral --ignore-user-config`，并显式关闭插件、Apps、Hooks、计算机控制和多代理能力。市场研究可以搜索公开资料；自动 RSS Adapter 不需要 API Key，单个资讯源失败会连同错误固化并由另一个源和 live search 补位；报告合成不启用搜索，只能读取通过验证的上游发现。未启用研究执行器时，报告明确保存为 `partial`，并且不会创建虚假的 Research Run。

`CODEX_BINARY=codex` 从后端的 PATH 查找可执行文件；也可指定绝对路径。
已知的旧 macOS 应用内路径会自动迁移到新的 `codex-cli/CodexCLI.app` 布局。
其他自定义路径不会被静默替换。创建报告前会检查执行文件和项目目录，
配置失效时直接提示原因，不再创建注定失败的研究任务。修改配置后需重启后端。

## 验证

报告正文与分析成果支持英语/中文：手动生成使用点击时的 `EN | 中文`
界面语言；直接调用生成 API 可传 `{"language":"en"}` 或 `{"language":"zh"}`，
省略时默认英语。每日自动报告的语言在系统设置中单独选择，默认英语。
语言随固化输入保存，断点续跑不会改变语言；已有报告保持原文，不自动翻译。

```bash
cd backend && cargo test
npm run typecheck
npm test
```

Web 的“系统设置”可维护股票报告的每日生成时间，并暂停或恢复自动生成；暂停不影响手动生成。“市场情报”只展示宏观与 A股、港股、美股持仓研究。页面顶部支持 `EN | 中文` 界面切换。

## 事实边界

Codex/Skills 只能读取固化输入并返回结构化候选结果。只有 Rust 验证器能把通过校验的研究结果写入研究表。股票研究可以为缺少 Intent 的精确持仓按所选报告语言生成候选草稿，但不能直接写入或启用 Intent；用户必须在持仓工作台审阅确认。Codex 不能直接修改账户、成交、持仓快照或执行交易；系统不接收或保存私钥。
