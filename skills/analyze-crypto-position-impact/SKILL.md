# Analyze Crypto position impact

Apply `apply-investment-research-standards`. Exclude pure Meme tokens; scope impacts to frozen Crypto positions and Intents.

## Workflow

1. Collect protocol/chain records, audited dashboards, governance proposals, security disclosures, token schedules, exchange notices, and regulator sources.
2. Distinguish nominal TVL or revenue changes from price-denominated effects and one-off incentives.
3. Evaluate usage quality, token value capture, supply/unlock/staking effects, security, governance, counterparty, exchange, regulatory, and liquidation risks.
4. Compare material changes with thesis, catalysts, invalidation and exit principles.
5. Return supported impact, confidence, contrary evidence, confirmation/invalidation conditions, conditional action, and data gaps.

## Refusal and self-check

Do not treat unaudited dashboards as exact, token price as protocol adoption, or governance proposals as final. Do not request keys or execute transactions. Verify chain/contract identity, cutoff, unit definitions, and frozen affected IDs.
